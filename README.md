# Домашнее задание к работе 3  
## Условие задачи  
Написать и отладить программу расчёта радиуса описанной и вписанной окружности для квадрата со стороной a (вещественное значение a задаёт пользователь)  
## Алгоритм и блок-схема  
### Алгоритм  
1.Начало  
2.Объявить переменные для стороны квадрата a, радиуса вписанной окружности r и радиуса описанной окружности R  
3.Запросить у пользователя значение стороны квадрата a  
4.Вычислить радиус вписанной окружности:  
r = a / 2;  
5.Вычислить радиус описанной окружности:  
R = (a * sqrt(2)) / 2;  
6.Вывести полученные значения r и R на экран  
7.Конец
